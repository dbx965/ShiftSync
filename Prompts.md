# ShiftSync Prompt Documentation

## Prompt 1

Create a React frontend and FastAPI backend for a student shift scheduling application connected to Supabase.

**Purpose:** Used to generate the initial application structure and architecture.

---

## Prompt 2

Review my existing ShiftSync project and create a complete implementation plan including FastAPI endpoints, React integration, CORS configuration, and Supabase storage.

**Purpose:** Used to analyse the project structure and generate an implementation plan.

---

## Prompt 3

My React application is displaying "Unable to connect to the server". Analyse the project and identify the cause.

**Purpose:** Used to troubleshoot frontend-backend communication issues.

---

## Prompt 4

Guide me through deploying the React frontend to Vercel and the FastAPI backend to Render.

**Purpose:** Used to deploy the application to cloud platforms.
